ALIPS.PK — WEBSITE STARTER PACKAGE
==================================

WHAT'S INCLUDED
- Responsive homepage for mobile and desktop
- Alips.pk logo and orange/black brand styling
- Technology, Perfumes and Electrical Accessories categories
- Product search and category filters
- Add-to-cart, quantity controls and cart subtotal
- Checkout form that prepares an order in WhatsApp
- About and contact sections

IMPORTANT BEFORE PUBLISHING
1. Open config.js.
2. WhatsApp number is configured as 923070458530 (Pakistan format).
   Pakistan example: 923001234567 (no +, spaces or dashes).
3. Open products.js and replace the sample product names, descriptions and prices with your actual products.
   The displayed prices are examples only.
4. To add product photos, upload them into the assets folder and set each product's image path in products.js.
5. Test the website on your phone before sharing it with customers.

GITHUB PAGES UPLOAD
1. Extract this ZIP file.
2. Open your GitHub repository: alipssport.github.io
3. Upload the CONTENTS of the alips-store folder (not the folder itself) to the repository's root.
4. If GitHub asks, replace the old index.html and add the other files/folders.
5. Keep the repository's existing custom domain configuration (CNAME) if it is already working.
6. Wait for GitHub Pages to publish, then open https://alips.pk.

CHECKOUT / PAYMENT NOTE
This version supports a working cart and checkout-to-WhatsApp order handoff. It does not collect online card payments or automatically save orders to a store database. A payment gateway/backend would be a separate integration.

PRODUCT MANAGEMENT NOTE
This is a static GitHub Pages website. To add or edit products, update products.js and upload the changed file to GitHub. There is no private admin dashboard in this starter package.
